# CareNova Frontend

React dashboard for clinic staff to monitor and manage AI-recovered leads.

## Planned screens
- **Dashboard** — KPIs: leads recovered, conversion rate, revenue recovered
- **Leads table** — filterable list with status, last contact, AI conversation log
- **Conversation view** — full WhatsApp thread per lead
- **Settings** — clinic profile, language preference, working hours

## Setup
```bash
npx create-react-app . --template typescript
npm install
npm start
```
